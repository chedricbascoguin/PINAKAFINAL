The PHP pages now load compiled Tailwind 3 CSS instead of the development CDN.
The existing page-specific fonts and brand colors are preserved.

After changing utility classes in PHP or root JavaScript files, rebuild from the
repository root (Node/npm required only on the build machine):

```powershell
npx.cmd --yes --package tailwindcss@3.4.17 tailwindcss -c tailwind-php.config.cjs -i styles/tailwind-php.input.css -o assets/tailwind-php.css --minify
```

Upload the rebuilt CSS and increment its `?v=1` URL version on the PHP pages to
invalidate cached styles. Hard refresh after the initial upload.

The screenshot's iframe sandbox and unload messages are not generated by the
local scanner code. Check the hosted page directly in a browser with extensions
disabled. If those messages remain, inspect the deployed iframe attributes and
response headers. The PDF detection and runtime connection messages also need
that browser check; this CSS change does not suppress console messages.
